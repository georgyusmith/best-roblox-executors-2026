## How to Read This Table

- **Version** — current release number of the executor.
- **OS** — supported operating system.
- **Keyless** — no key system required to use it.
- **Level** — script execution power. Level 8 is top-tier, Level 7 is standard.
- **Script Hub** — includes a built-in script library.
- **Auto-Update** — updates automatically after game patches.
- **Rating** — community feedback score out of 5.
